## Установка (macOS 12+, Apple Silicon)
1. Скачайте `.dmg` ниже, откройте и перетащите **VidUniq** в **Applications**.
2. Запустите VidUniq.

> ⚠️ **macOS скажет «не удаётся проверить разработчика» или «приложение повреждено» — это нормально.**
> Приложение не подписано сертификатом Apple ($99/год), как и любой бесплатный open-source проект без него.
> Код открыт, сборка сделана публично в GitHub Actions — ничего лишнего внутри нет.
>
> **Открыть один раз любым способом:**
> - дважды кликнуть **«Снять карантин.command»** из образа (после копирования в Applications), или
> - *Системные настройки → Конфиденциальность и безопасность → «Открыть всё равно»*, или
> - в Терминале: `xattr -cr /Applications/VidUniq.app`

⭐ Понравилось — поставьте звезду: при 100 ⭐ появятся сборки для Windows и macOS Intel ([roadmap](https://github.com/f0q/Video-Uniqueizer#roadmap)).

## Install (macOS 12+, Apple Silicon)
1. Download the `.dmg` below, open it and drag **VidUniq** to **Applications**.
2. Launch VidUniq.

> ⚠️ **macOS will say "cannot verify the developer" or "app is damaged" — this is expected.**
> The app is not signed with an Apple certificate ($99/year), like any free open-source project without one.
> The source is open and this build was made publicly in GitHub Actions.
>
> **Open it once using any of these:**
> - double-click **«Снять карантин.command»** (remove quarantine) from the disk image after copying to Applications, or
> - *System Settings → Privacy & Security → "Open Anyway"*, or
> - Terminal: `xattr -cr /Applications/VidUniq.app`
